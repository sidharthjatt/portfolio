How I work

Three habits I keep across projects.

01

Rules before results

The accept rule for an experiment gets written down before it runs. Reasonable Doubt's pre-registration runs past 6,000 lines, and when a rule turns out wrong, the fix goes in as a dated amendment, not an edit.

02

Failures stay in the record

Two of Reasonable Doubt's three planned tiers were dropped because they lost on measurement. Four pieces of Honest Mistake's third layer were cut and the reasons are in the repo. Predictive Engine keeps every rejected idea next to the one that passed.

03

Other people can check it

Each project is public and either live or reproducible from a clean clone. Honest Mistake lets you run the audit yourself with your own API key, and RegretZero's dashboard imports the same module that produced its README numbers.
